# DocLib

DocLib — библиотека документов для удобного хранения и поиска сведений
о физически сохранённых документах.

## Назначение

Удобное добавление, хранение сведений и поиск документов из разных
областей.

## Целевая аудитория

Архивы, библиотеки и другие организации, которым нужно хранить большие
объёмы документов в строгом порядке.

## Предметная область

Архивное дело и документооборот.

## Основные сущности

- документ.

## Основные функции

- добавление документов;
- поиск документов по названию;
- хранение данных в JSON-файле;
- загрузка данных при запуске приложения.
